# 要件定義 — 麻雀点数計算ドリル

v0.2（2026-10-30）

## 1. 目的

点数計算を「早見表の暗記」から「手牌を見て全部自分で出せる」まで、段階を踏んで練習できるようにする。

## 2. 対象ユーザー

| 使い方                     | 設定                                      |
| -------------------------- | ----------------------------------------- |
| 点数計算を覚えたい初中級者 | 解説 ON（なぜその符・点数になるかを表示） |
| 反復練習したい人           | 解説 OFF（テンポよく次の問題へ）          |

## 3. モード（難易度）

| Lv  | モード | 出題                                      | 答えるもの               |
| --- | ------ | ----------------------------------------- | ------------------------ |
| 1   | 早見表 | 符・翻・親/子・ツモ/ロン                  | 点数                     |
| 2   | 符計算 | 手牌＋和了条件（待ち・ツモ/ロン・門前か） | 符                       |
| 3   | 役・翻 | 手牌＋和了条件（場風・自風・ドラ）        | 役と翻数                 |
| 4   | 総合   | 手牌＋和了条件                            | 点数（必要なら符・翻も） |

モードの中でも難しさを調節できるようにする。

- 回答形式: 4択（易）／数値入力（難）
- 絞り込み: 例）Lv1 で「満貫未満のみ」「親のみ」

## 4. 機能要件

- モード・出題数・解説 ON/OFF・回答形式を選んで開始する
- 1問ごとに正誤を判定し、解説 ON なら解説を表示する
- 子のツモは「子の支払い/親の支払い」の2つで答える（卓での申告と同じ形）。親のツモは「◯◯オール」で答える
- 終了時に、その回の正答率と間違えた問題を一覧表示する。**保存はしない**（リロードで消える）

## 5. 問題の作り方

点数計算エンジン（手牌 → 役・符・翻・点数）を自作し、問題はランダムに生成する。

- **理由**: Lv2〜4 の正解を出すにはどのみちエンジンが要る。手作りの問題集は問題数が足りなくなり、正解の書き間違いも防げない
- **品質**: 点数が分かっている手牌をそろえ、Vitest で徹底的にテストする。正解が間違っているドリルは致命的なので、ここに一番手間をかける

## 6. 採用ルール（Mリーグルール準拠）

**一次情報**: https://m-league.jp/about/ の第1章〜第9章。
2026-10-30 はサイトがメンテナンス中で本文を読めなかった。そのため下の表は、複数の二次情報が一致した内容をもとにしている。「要確認」は、メンテナンス明けに公式で確かめてからエンジンに組み込む。

| 項目                                                              | 扱い                               | 状態            |
| ----------------------------------------------------------------- | ---------------------------------- | --------------- |
| 切り上げ満貫                                                      | あり（30符4翻・60符3翻は満貫）     | 二次情報で一致  |
| 数え役満                                                          | なし（11翻以上はすべて三倍満）     | 二次情報で一致  |
| 1種類の役満が倍になる形（国士13面・四暗刻単騎・純正九蓮・大四喜） | 役満1つ分として扱う                | 二次情報で一致  |
| 異なる役満の複合                                                  | 多数説は「あり」、反対の記述もある | **要確認**      |
| 赤ドラ                                                            | 5萬・5筒・5索の各1枚、計3枚        | 二次情報で一致  |
| 喰いタン・後付け                                                  | どちらもあり（1翻縛り）            | 二次情報で一致  |
| 連風牌の雀頭                                                      | 2符                                | 二次情報で一致  |
| ピンフツモ                                                        | 20符（ツモ符は付かない）           | 二次情報1件のみ |
| 嶺上開花のツモ符                                                  | 2符が付く                          | **要確認**      |
| 喰いピンフ形のロン                                                | 二次情報にも記載がない             | **要確認**      |
| 流し満貫・人和                                                    | なし                               | 二次情報で一致  |
| 本場・供託                                                        | 初版のドリルでは扱わない           | —               |

調査の出典 URL と食い違いの詳細は `docs/research/mleague-rules.md` を参照。

## 7. 非機能要件

- スマホ優先のレスポンシブ（片手で解ける）
- 技術: Next.js + TypeScript（strict）+ Vitest + Vercel
- ログイン・DB なし
- 牌画像: [FluffyStuff/riichi-mahjong-tiles](https://github.com/FluffyStuff/riichi-mahjong-tiles)（CC0、SVG。2026-10-30 に LICENSE.md を確認）。一般的な絵柄で、赤5と裏面もそろっている。横向きの牌は CSS の回転で表示する

## 8. 初版の範囲外

成績の保存、ログイン、三人麻雀、ローカル役、本場計算

## 9. リリースの区切り

1. **MVP**: Lv1（早見表）＋ 解説 ON/OFF ＋ 4択/数値入力
2. Lv2: 手牌の表示と符計算エンジン
3. Lv3: 役判定エンジン
4. Lv4: 総合
