# 要件定義 — 麻雀点数計算ドリル

v0.4（2026-10-30）

## 1. 目的

点数計算を「早見表の暗記」から「手牌を見て全部自分で出せる」まで、段階を踏んで練習できるようにする。

## 2. 対象ユーザー

| 使い方                     | 設定                                      |
| -------------------------- | ----------------------------------------- |
| 点数計算を覚えたい初中級者 | 解説 ON（なぜその符・点数になるかを表示） |
| 反復練習したい人           | 解説 OFF（テンポよく次の問題へ）          |

## 3. モード（難易度）

| Lv  | モード | 出題                                      | 答えるもの               |
| --- | ------ | ----------------------------------------- | ------------------------ |
| 1   | 早見表 | 符・翻・親/子・ツモ/ロン                  | 点数                     |
| 2   | 符計算 | 手牌＋和了条件（待ち・ツモ/ロン・門前か） | 符                       |
| 3   | 役・翻 | 手牌＋和了条件（場風・自風・ドラ）        | 役と翻数                 |
| 4   | 総合   | 手牌＋和了条件                            | 点数（必要なら符・翻も） |

モードの中でも難しさを調節できるようにする。

- 回答形式: 4択（易）／数値入力（難）
- 絞り込み: 例）Lv1 で「満貫未満のみ」「親のみ」

## 4. 機能要件

- **点数計算機**（2026-10-30 追加）: 手牌・副露・和了牌・和了条件・ドラ表示牌・本場を入力すると、役・符・点数と解説を出す。ドリルでは出題しない手（双碰のロン、役満など）も、注記を付けて計算する。詳細は `docs/features/calculator.md`
- モード・出題数・解説 ON/OFF・回答形式を選んで開始する
- 1問ごとに正誤を判定し、解説 ON なら解説を表示する
- 子のツモは「子の支払い/親の支払い」の2つで答える（卓での申告と同じ形）。親のツモは「◯◯オール」で答える
- 終了時に、その回の正答率と間違えた問題を一覧表示する
- **成績を端末内に保存する**（2026-10-30 に方針を変更。当初は保存しない方針だった）。保存先は localStorage で、ログインは不要。レベルごとの正答率、苦手な分類、直近の履歴を「成績」の画面で見られる。詳細は `docs/features/history.md`

## 5. 問題の作り方

点数計算エンジン（手牌 → 役・符・翻・点数）を自作し、問題はランダムに生成する。

- **理由**: Lv2〜4 の正解を出すにはどのみちエンジンが要る。手作りの問題集は問題数が足りなくなり、正解の書き間違いも防げない
- **品質**: 点数が分かっている手牌をそろえ、Vitest で徹底的にテストする。正解が間違っているドリルは致命的なので、ここに一番手間をかける

## 7. 非機能要件

- **さまざまなデバイスで使える**（2026-10-30 決定）。スマホだけでなく、タブレット・PC でもそれぞれに合ったレイアウトにする
  - スマホ（縦）: 片手で解ける。押す場所は親指の届く下半分に寄せる
  - タブレット・PC: スマホ用の細い列を中央に置くだけにしない。広い画面では、問題と回答・解説を横に並べるなど、画面の幅を活かす
  - PC: マウスとキーボードでも操作できる（選択肢を数字キーで選ぶ、Enter で次へ など）
  - 画面を変えたら、最低でも 375px（スマホ）・768px（タブレット）・1280px（PC）の3つの幅で見た目を確かめる
- 技術: Next.js + TypeScript（strict）+ Vitest + Vercel
- ログイン・DB なし（成績は端末内の localStorage に保存する）
- 牌画像: [FluffyStuff/riichi-mahjong-tiles](https://github.com/FluffyStuff/riichi-mahjong-tiles)（CC0、SVG。2026-10-30 に LICENSE.md を確認）。一般的な絵柄で、赤5と裏面もそろっている。横向きの牌は CSS の回転で表示する

## 8. 初版の範囲外

端末をまたいだ成績の同期、ログイン、三人麻雀、ローカル役、国士無双（和了形の判定に含めていない。手牌の生成でも出ないので、出題には影響しない）

## 9. リリースの区切り

1. **MVP**: Lv1（早見表）＋ 解説 ON/OFF ＋ 4択/数値入力（2026-10-30 完成。`docs/features/drill-lv1.md`）
2. **Lv2**: 手牌の表示と符計算エンジン（2026-10-30 完成。`docs/features/drill-lv2.md`）
3. **Lv3**: 役判定エンジン（2026-10-30 完成。`docs/features/drill-lv3.md`）
4. **Lv4**: 総合（2026-10-30 完成。`docs/features/drill-lv4.md`）
5. **コードを一緒に見る**（2026-10-30 決定）: すべての実装が終わったら、コードを解説しながら user と一緒に全部見る。プログラミングの勉強と、コード・エラー処理・セキュリティの確認を兼ねる
