# セキュリティ

2026-10-30 に点検した結果と、入れている対策。

## 点検の結果（問題なし）

| 観点                         | 状態                                                                                                 |
| ---------------------------- | ---------------------------------------------------------------------------------------------------- |
| 秘密情報                     | リポジトリと履歴に `.env` やトークンはない。`.env*`・`.vercel` は `.gitignore` で除外                |
| XSS                          | `dangerouslySetInnerHTML`・`innerHTML`・`eval` を使っていない。文字は React がエスケープして表示する |
| 外部への通信                 | 実行時に外部へ送る処理はない。成績は端末内（localStorage）だけ                                       |
| 保存データ                   | 読み込むときに1件ずつ形を検証する（`src/features/history/history.ts`）                               |
| サーバー側のファイル読み込み | OGP 画像の生成だけ。ファイル名は固定の値で、利用者の入力を使わない                                   |
| 依存パッケージ               | `npm audit` で脆弱性なし                                                                             |
| CI                           | GitHub Actions の既定の権限は読み取りのみ。main はブランチ保護あり                                   |

## セキュリティヘッダー

`next.config.ts` の `SECURITY_HEADERS` で、すべてのページに付ける（値はあちらが正）。

- 他のサイトへの埋め込みの禁止（`Content-Security-Policy: frame-ancestors` と `X-Frame-Options`）
- ファイルの種類の推測の禁止（`X-Content-Type-Options`）
- 他のサイトへ渡す URL を絞る（`Referrer-Policy`）
- 使わない機能（カメラ・マイク・位置情報など）の禁止（`Permissions-Policy`）

HSTS（常に HTTPS で接続させる指示）は Vercel が付ける。

## 入れていないもの

- **スクリプトの読み込みを限定する本格的な CSP**: Next.js ではリクエストごとの nonce などの作り込みが要り、静的に生成しているページの作りも変わる。ログインも個人情報もない今の規模では、効果に見合わないので入れていない
- **GitHub Actions のアクションを SHA で固定すること**: 個人のポートフォリオでは、バージョンのタグ（`@v4`）の指定で十分と判断した
