# Lv3 役・翻モード

手牌と和了条件（場風・自風・ツモ/ロン・リーチ）を見せて、成立している役を答えるドリル。役と翻数の根拠は `docs/requirements.md` の 6 章（公式ルール 第9章）。

## 構成

| 場所                                | 役割                                                                              |
| ----------------------------------- | --------------------------------------------------------------------------------- |
| `src/features/yaku/yakuList.ts`     | 役の一覧（`YAKU`）と、門前・副露での翻数。手牌だけで判定できる役満の一覧          |
| `src/features/yaku/evaluateYaku.ts` | 1つの解釈について、成立する役を判定する                                           |
| `src/features/yaku/analyzeHand.ts`  | 全解釈から最も高い点の解釈を選ぶ（高点法、第6章第5条）。出題に使えるかも判定する  |
| `src/features/generate/`            | 手牌の組み立て（`buildHand`）と、Lv2（`fuHand`）・Lv3（`yakuHand`）の受け入れ条件 |
| `src/features/drill/yakuAnswer.ts`  | Lv3 の答え（役の組み合わせ＋翻数）と4択の誤答作り                                 |
| `src/components/drill/lv3View.tsx`  | Lv3 の問題・解説。「役を選ぶ」は `YakuPicker`                                     |

## 決めたこと

- **役は解釈ごとに判定する**。一盃口・平和・三暗刻などは、面子と待ちの取り方で成否が変わるため
- **出題しない手**（`analyzeHand`）:
  - 最高点の解釈が複数あって、役の組み合わせが違う手
  - 役満
  - 双碰待ちのロン
- **ドラ（赤5）は混ぜない**。Lv3 は役の練習。ドラは Lv4 で扱う
- **門前の手にリーチを付ける割合は 6割**（`yakuHand.ts` の定数）。リーチだけの手に偏らないようにするため
- **役を狙って手を組む**（`buildHand.ts` のテーマ）。混一色・清一色・対々和・全帯么九・断么九・三色同順・一気通貫・一盃口・役牌。狙いの面子がいつも副露にならないよう、並びを混ぜてから副露を選ぶ
- **4択の誤答**: 正解から「1つ抜く」「1つ足す」「間違えやすい役と入れ替える」で作る
- **「役を選ぶ」**: その手で付きうる役だけを翻数ごとに並べる。副露していて付かない役（◎）は出さない
- **生成の層**: 手牌の生成は `features/generate/` に置く。`hand` と `yaku` の両方を使うため。`hand` の中に置くと、`hand → yaku → hand` の循環 import になる
