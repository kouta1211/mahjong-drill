# Lv1 早見表モード

符・翻・親子・ツモロンを見せて、点数を答えるドリル。要件は `docs/requirements.md` の 3〜4 章。

## 構成

| 場所                                 | 役割                                                                       |
| ------------------------------------ | -------------------------------------------------------------------------- |
| `src/features/score/`                | 点数計算（React に依存しない）。ルールの値は `rules.ts` の `MLEAGUE_RULES` |
| `src/features/score/officialTable.*` | Mリーグ公式の早見表との全マス照合テスト                                    |
| `src/features/drill/`                | 出題・選択肢・判定・解説・状態遷移（`drillReducer`）                       |
| `src/components/drill/`              | 画面。入口は `Drill.tsx`（Client Component）                               |

## 決めたこと

- **乱数は描画中に使わない**: 問題と4択の選択肢は「はじめる」を押したときに `createStartAction` でまとめて作り、reducer に渡す。描画中に作ると、Strict Mode の二重描画で選択肢が変わるため
- **乱数は差し替えられる**: `Drill` の `rng` に固定の乱数（`seededRng`）を渡すと、テストで出題を再現できる
- **4択の誤答**: 同じ親子・ツモロンの答えのうち、正解に点数が近いものから選ぶ。表記の形（オールなど）だけでは正解が分からない
- **ありえない組み合わせは出題しない**: `validCombos.ts` の `isPossibleCombo`。公式の早見表の空欄と一致することをテストで守っている
- **成績は保存しない**: リロードすると消える（要件 4 章）

## デバイスごとのレイアウト

要件は `docs/requirements.md` の 7 章。ブレークポイントは Tailwind の標準値（`md` をタブレット、`lg` を PC）を使う。

| 画面   | スマホ         | タブレット（`md`） | PC（`lg`）                                                   |
| ------ | -------------- | ------------------ | ------------------------------------------------------------ |
| 設定   | 1列            | 2列                | 2列（幅を `max-w-3xl` に制限）                               |
| 出題中 | 1列。4択は 2×2 | 1列。4択は横一列   | 左に問題（スクロールしても見える位置に固定）、右に回答と解説 |
| 結果   | 1列            | 間違えた問題を2列  | 同左                                                         |

- **キーボード**: 1〜4 で選択肢を選ぶ（`ChoiceAnswer` が `window` の keydown を見る。入力欄にいるときや、修飾キー付きの操作は無視する）。「次へ」は表示時にフォーカスされるので、Enter で進める
- **キーのヒント**: マウスなどを使う端末にだけ出す（Tailwind の `pointer-fine:`）。タッチ端末には出さない
