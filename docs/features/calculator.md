# 点数計算機

手牌・副露・和了牌・和了条件（場風・自風・ツモ/ロン・立直）・ドラ表示牌・本場を入力すると、役・符・点数と解説を出す。設定画面の「点数計算機」から開く。

## 構成

| 場所                                                        | 役割                                                                                  |
| ----------------------------------------------------------- | ------------------------------------------------------------------------------------- |
| `src/features/calculator/calculate.ts`                      | 入力の検証と計算。エラーの一覧か、結果と注記を返す純粋な関数                          |
| `src/features/yaku/analyzeHand.ts` の `rankInterpretations` | 解釈を点数で比べる（高点法）。ドリルの `analyzeHand` と共通                           |
| `src/features/score/calcScore.ts` の `calcYakumanScore`     | 役満の点数。異なる役満の複合は2倍・3倍（公式ルール 第6章第6条）                       |
| `src/components/calculator/`                                | 画面。入力の状態は `calculatorReducer`、牌の選択は `TilePalette`、入れ先は `TileSlot` |

## 決めたこと

- **入力の検証は理由を出す**:
  - 和了牌がない
  - 手牌の枚数（「あと n 枚」）
  - 副露の形
  - 同じ牌が5枚以上（ドラ表示牌も含める）
  - 赤5は各色1枚まで
  - ドラ表示牌は 1 ＋ 槓の数まで
  - 裏ドラは立直のときだけ
  - 本場の範囲
- **和了形と役の判定**: 和了形でない手、役がない手（ドラは役にならない）、国士無双（対象外）は、その旨を伝える
- **ドリルでは出題しない手も計算し、注記を付ける**:
  - 双碰のロン: WRC ルールの扱い（明刻）で計算する
  - 暗槓を含む九蓮宝燈の形: 役満にしない
  - 同じ点数の別解釈がある手: 役の内訳はそのうちの1つ
- **入力は入れ先を選んでから牌を押す**:
  - 和了牌を入れたら、入れ先は手牌に戻る
  - 副露の入れ先は、枚数が埋まったら手牌に戻る
  - 入れた牌を押すと外せる
- **スマホ・タブレットでは、牌のパレットを画面の下に固定する**: 入れ先の枠とパレットの間を、スクロールで行き来しなくて済むようにする
- **計算は入力のたびにやり直す**: 計算は軽いので、「計算する」ボタンは置かない
